### 🚀 Featured Engineering & Research

#### 🎵 [Music Score Assistant](https://github.com/MikeCillo/MusicScoreAssistant)
*IoT multi-sensory assistive system developed at Musimathics Lab (B.Sc. Thesis).*
- Enables visually impaired musicians to "read" scores via haptic (vibration) & auditory cues.
- **Stack:** ESP32, FreeRTOS, C++, WebBluetooth, JavaScript, Docker.

#### 🏛️ [Csar Compiler](https://github.com/MikeCillo/Csar)
*A complete, custom-built compiler translating a Latin-keyword language into highly optimized LLVM IR.*
- Built from scratch in Python (Lexical/Syntactic Analysis to Semantic Type Checking).
- Generates industry-standard LLVM IR for blazing-fast native executables via Clang.

#### 🌱 [RockMerce](https://github.com/MikeCillo/RockMerce)
*Green IT project transforming a legacy e-commerce platform into a sustainable ecosystem.*
- Achieved a **90% reduction in CO₂ per visit**, eliminated memory leaks via Try-With-Resources, and implemented OLED-friendly dark mode.
- **Stack:** Java/JSP, SonarQube, JMeter, EcoIndex metric analysis.

#### 🔧 [junit-to-jmh](https://github.com/alniniclas/junit-to-jmh) (Open Source Contributor)
*Automated benchmark generation tool bridging functional testing and microbenchmarking.*
- Converts JUnit 4/5 test suites directly into JMH microbenchmarks using AST inlining and Wrapper strategies.
- **Stack:** Java 17, JMH, JUnit 5, Gradle.
